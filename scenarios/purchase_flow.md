# User Story: Swag Labs E-Commerce Purchase Flow

## Scenario Description
Navigate to the SauceDemo application, log in using standard credentials, add the backpack item to the shopping cart, proceed to checkout, and verify order totals.

## Requirements
1. Navigate to https://www.saucedemo.com.
2. Log in with username "standard_user" and password "secret_sauce".
3. Add the "Sauce Labs Backpack" to the cart.
4. Open the shopping cart and click Checkout.
5. Verify checkout total is $32.39.
